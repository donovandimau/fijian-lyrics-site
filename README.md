# Fijian Lyrics
A searchable static site of Fijian song lyrics, built with plain HTML, CSS and JS and no build step. Open `index.html` to view it.
To add a song, add an entry to `songs.js`. Fill in `lyricsFijian` or `translationEnglish` only when the text is verified as public domain, traditional, or official, and always include `source`.
Deployed on Vercel as a static site with no framework and the root as the output directory.
